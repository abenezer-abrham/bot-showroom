# 🤖 BotMatrix — Premium Telegram Bots Showroom & Managed Servicing

A high-converting, Spotify-inspired web showroom for showcasing and selling production-ready Telegram bots under two flexible ownership models: **One-Time Buyout (Lifetime Source Code Ownership)** and **Monthly Managed Cloud Servicing (99.9% Uptime SLA)**.

Developed by **Abenezer Abrham** ([@abenezer_abrham](https://t.me/abenezer_abrham)).

## ✨ Features

- **Spotify-Grade Aesthetic**: Obsidian dark theme (`#090a0f`), vibrant Spotify green & cyan glowing accents, and glassmorphic cards.
- **Dynamic Dual-Model Deals**: Instantly switch between One-Time Source Code Buyout and Monthly Managed Servicing.

## 🚀 Quickstart

### 1. Clone & Install
```bash
git clone https://github.com/abenezer-abrham/bot-showroom.git
cd bot-showroom
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### 3. Production Build
```bash
npm run build
npm run preview
```

---

## ☁️ Deploy to Vercel

### Method 1: Deploy with Vercel CLI
```bash
npx vercel
```

### Method 2: Import via Vercel Dashboard
1. Go to [vercel.com/new](https://vercel.com/new).
2. Select your repository `abenezer-abrham/bot-showroom`.
3. Framework Preset: **Vite**.
4. Click **Deploy**.
